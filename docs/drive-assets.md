# Drive asset source and placement policy

Source folder: https://drive.google.com/drive/folders/1C2ndUsrDOnTg4p_IY9LsKIeKafoH7jCJ?usp=sharing

The current site uses a curated set of original images from this folder. Banner artwork is intentionally used once only: `ahmed-brand-header.jpg` appears in the Social Studio section. The previous repeated crop variants (`ahmed-brand-square.jpg`, `ahmed-brand-story.jpg`, and `ahmed-brand-cover.jpg`) are not used in the redesigned page.

The Work Archive section uses distinct, non-banner source images exactly once each. Each card has a factual label describing the visible material; no client result, testimonial, or company relationship is inferred from an image alone.
